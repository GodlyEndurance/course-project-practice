What is the purpose of a Git commit?
- To record what files were changed/added/removed and a message explaining said change. 
- Without it, there will be no way to track the history of the push and pull


What is the difference between git push and git pull?
- One sends data to the repository and creates a new version
- One retrieves data from the repository and uses some version

Why might a development team use branches?
- To ensure that people do not overwrite someone's work while doing the same task.

What part of Git/GitHub was most confusing to you?
- The deleting part. When you want to delete a remote branch (a branch from Github), it doesn't delete the local branch. You have to switch to the main branch again to fully delete it.
